# Título del Proyecto
ExamenMaquetacionCSS_GarciaSalamancaAngel

## Descripción del Proyecto
Este proyecto examina las habilidades de maquetación CSS, utilizando principalmente CSS puro para crear una página web estéticamente agradable y funcional. El enfoque está en demostrar el dominio de CSS para el diseño web responsivo y adaptativo.

## Contenido de la Publicación
- Archivo HTML (index.html)
- Hoja de estilos CSS (styles.css)
- Imágenes (logo1.svg, salon1.jpg, salon2.jpg, salon3.jpg, salon4.jpg, salon5.jpg, salon6.jpg, salon7.jpg)

## Desarrollo del Proyecto
Este examen implicó desafíos como la implementación de un diseño que se ajustara a múltiples dispositivos sin perder calidad visual ni funcionalidad. Las tecnologías usadas incluyen HTML5 y CSS3, enfocándose en técnicas avanzadas de CSS como flexbox y grid para lograr una maquetación precisa.
